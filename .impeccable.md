# .impeccable.md

## Design Context

### Users

CEO, COO, and leadership team/managers of all Prospera business units. Primary usage is during weekly leadership meetings (referencing specific items on a shared screen) and individual laptop pulse-checks between meetings. Mobile is a secondary consideration.

### Core Questions (priority order)

1. "Are we on track?" — overall progress is the hero
2. "What's stuck?" — blocked items surfaced immediately
3. "What happened this week?" — chronological detail layer
4. "How is each team performing?" — department drill-down

### Brand Personality

Clean, authoritative, data-confident. Bloomberg meets Stripe — precise, structured, respects the viewer's time. Not cold, but decisive.

### Brand System (from Brand Guide HP_v5.pdf)

**Colors — official palette:**

- Navy: `#1F4E86` (primary)
- Teal: `#6ABEBE`
- Dark Teal: `#368496`
- Gold: `#FCB614`
- Orange: `#EE8522`
- Red: `#DD3A3B`
- Gray (logo): `#404040`

**Typography — adapted for dashboard context:**

- Primary/body: Heebo (Google Fonts) — clean sans-serif, full weight range
- Display/accent: Playfair Display (Google Fonts) — used sparingly for page title and section headers
- Logo: Intervogue (not used in UI)

**Logo:** PROSPERA wordmark with chevron/arrow mark. Primary in navy `#1F4E86`. Embedded as base64 WebP in header.

### Aesthetic Direction

- Light mode only
- Data-dense but not cluttered — strong information hierarchy
- Semantic status colors for done/in-progress/blocked
- Gold `#FCB614` for decorative use only (fails AA contrast on white)
- Tinted neutrals over pure grays — lean toward the navy hue
- No glassmorphism, no gradient text, no decorative sparklines
- Single-file static HTML — no framework, no build step

### Design Principles

1. **Answer first** — Lead with the conclusion, not raw data. The hero zone answers "are we on track?" before the user scrolls.
2. **Surface problems** — Blocked items get a dedicated callout section. The CEO shouldn't have to filter to find trouble.
3. **Respect the time** — Compact filters (search visible, dropdowns on demand). Condensed table (5 columns visible, details expand on click). No wasted space.
4. **Brand-faithful, context-adapted** — Use the official Prospera palette and typography, but optimize for data readability over marketing aesthetics.
5. **Accessible by default** — WCAG AA contrast, semantic HTML, `prefers-reduced-motion` support.

### Information Architecture

1. **Header** — Logo, title, data freshness indicator (compact)
2. **Hero zone** — Single dominant progress indicator with secondary stats subordinate
3. **Goal progress** — How each strategic goal is tracking
4. **Blocked callout** — Dedicated section listing blocked items with owner and reason (hidden when count is zero)
5. **Filters** — Search bar always visible, dropdown filters behind a toggle, cascading (department filters team options)
6. **Detail table** — Columns: Responsible, Topic, Status, Goal, Updated. Department/Team in group headers. Details/Notes expand on row click.

### Scope

Visual redesign + minor UX enhancements. No new data features. Same Google Sheets data source, same GitHub Pages deployment.
